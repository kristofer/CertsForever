Using the API

curl -H "Authorization: Bearer $TOKEN" \
     -H "Content-Type: text/csv" \
     --data-binary @cohort.csv \
     "{{.BaseURL}}/api/v1/import?notify=true"
POST /api/v1/import
Issue from a CSV (same format as the Issue page). ?notify=true emails students.
GET /api/v1/certificates
List; filter with course, cohort, q, status, claimed.
GET /api/v1/certificates/{id}
One certificate.
POST /api/v1/certificates/{id}/revoke
Body {"reason": "…"}.
POST /api/v1/certificates/{id}/claim-link
New link for the student; ?notify=true emails it.
GET /api/v1/courses, POST /api/v1/courses
List or create/update courses.
GET /api/v1/stats
Per-course numbers.
